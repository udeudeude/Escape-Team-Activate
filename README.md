# Escape Team Activate

An original print-and-play mystery / puzzle design project built to integrate with the [Escape Team Mission Editor](https://www.escape-team.com/create).

**Status:** concept exploration; no playable mission has been published or playtested yet.

## Current work

- [Three competing mission concepts and design constraints](docs/CONCEPTS.md)
- Proposed progression: choose an original physical mechanism → build a 10–15-minute paper prototype → test solution logic and print tolerances → playtest blind → expand into a full 5-checkpoint mission → test in the official app.

## Concept shortlist

1. **The Last Broadcast** — uncanny radio mystery; reversing the assumed direction of a transmission changes the meaning of old evidence.
2. **The House That Wasn't There** — architectural mystery; reconstruct a building from contradictory physical surveys.
3. **The Ministry of Misplaced Hours** — surreal procedural mystery; administrative rules conceal an injustice.

## Compatibility

All planned missions use Escape Team's five-digit answer checkpoints while keeping the real puzzles in the printable materials. We will not reproduce the publisher's paid puzzles.

**Platform test status:** editor documentation examined; no Android or iOS app emulator is available in the current assistant execution environment. Real-device validation remains necessary.
